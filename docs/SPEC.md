# ほしふる迷宮 — ゲーム仕様 v1

## コンセプト

- 「不思議のダンジョン」系のターン制ローグライク。エンドレス型で、どこまで高くのぼれるかを競う。
- 世界観はおとぎ話風の魔法ファンタジー（雲の上に浮かぶ迷宮、呪われた道具、鏡、カボチャ、ろうそく、いばら……）。マップは雲の海に浮かぶ石の足場として描かれる。
  キャラクター・アイテム・モンスターの名称とデザインはすべてオリジナル。
- 主人公はランタンを持った子どもの冒険者「ルミ」。

## ゲームループ

- 1F から開始し、階段で上へ。クリアはない。
- 死亡でゲームオーバー → 結果画面（到達階・レベル・討伐数・ターン数・所持金・スコア）。
- スコア = 最高到達階 × 1000 + 所持金 + 累計経験値。
- 10 階ごとに環境（テーマ）が変わる: くもの回廊（夕暮れ）→ ゆうやけの庭 → つきよのはし → オーロラのとう → ほしのうみ（以後ローテーション）。高くのぼるほど空は宇宙に近づく。
- 10 階ごとに階段の部屋に番人（ボス級）が待つ。倒すと良い装備（+2 以上）と金貨を落とす。
  番人は 4 種をローテーションし、周回ごとに強化される。
- 31F 以降、通常モンスターは深さに応じて能力値が上昇し続ける（+5% / 階）。

## マップ

- 52 × 30 マス。4 × 3 のセクターに分け、各セクターに部屋（82%）または通路の中継点を置き、
  スパニングツリー＋追加エッジで接続する。行き止まりは除去。全域の連結性を検証。
- 部屋は 4〜9 × 3〜6 マス、最低 5 部屋。
- 視界はシレン方式: 部屋の中では部屋全体（壁・入口含む）、通路では隣接 8 マス。探索済みの範囲は記憶され、右上のミニマップと [M] の全体マップに表示。
- 斜め移動・斜め攻撃は壁の角をすり抜けられない（角抜け禁止）。

## プレイヤー

- 初期値: HP 15、Lv 1、ちから 8、持ち物 16 個。初期装備は「ちいさなナイフ」、「ひかりの実」1 個、「木の矢」8 本。
- 攻撃力 = ちから + 武器攻撃力(+補正値) + floor(Lv / 2)。防御力 = 盾防御力(+補正値)。
- ダメージ = 攻撃力 × 0.9375^防御力 × (0.875〜1.125)。最低 1。命中率: プレイヤー 92%、敵 88%（番人 95%）。
- レベルアップ: 必要経験値は 6 × 1.38^(Lv−2) を累積。最大 HP +5（Lv 21 以降 +4）。
- HP は毎ターン `maxHp / 150 + 0.02` ずつ自然回復。
- 行動: 移動・攻撃（素振り）・アイテム使用・投擲・装備 = 1 ターン。向き変更 = 0 ターン。
- 速度: 通常 100、はやい 200、おそい 50（エナジー方式。100 ごとに 1 行動）。

## アイテム

- 拾う: 乗ると自動（持ち物がいっぱいなら乗るだけ）。金貨は所持金に加算。
- 投げる: 向いている方向へ最大 10 マス直進。最初の敵に命中（90%）。実は効果を与えて消滅、矢は消滅、それ以外は敵の足元に落ちる。
- 杖: 回数制。向いている方向の最初の敵に効果。

## 罠（8 種）

踏むまで見えない。見える罠は 50% で回避。何もない隣接マスへ素振りすると、その罠が見つかる。

かぜのわな（つむじ風で次の階へ）/ どくばり（3 ダメージ・ちから −1）/ ワープ / まよい（混乱）/ さび（盾 −1）/ ねむり / じらい（HP 半減・周囲の敵に 30）/ しょうかん

## 店

- 入口が 1 つだけの部屋（13% / 階、2F 以降）。商品には値札。店主は入口脇に立つ。
- 商品を持つと「未払い」になり、店主が入口をふさぐ。店主に話しかけて合計額を払う。
- 未払いのアイテムは使えない（棚に戻すことはできる）。自分のアイテムを店内で置くと買い取り提示（定価の半額）。
- 未払いのまま店の外へ出る（ばしょがえの杖、かいだんのページ等）と店主が激怒し、ばんぺい 2 体が駆けつける。
- 階段は店の中には生成されない。店内に罠はない。

## モンスターハウス

- 3F 以降 10% / 階。大部屋に敵（眠っている）とアイテムが大量に配置される。入室すると全員が目を覚ます。

## 状態異常

- ねむり: 数ターン行動不能（自動でターンが進む）。
- 混乱: 移動方向が 75%、攻撃・投擲の方向が 50% でランダムに。
- はやい／おそい: 速度 200 / 50。
- ちから低下: 毒・どくどくの実で −1。きよめの実で元に戻る。

## UI / 操作

- 上部 HUD: 階・Lv・HP バー・ちから・金貨・ターン・状態・装備。下部にメッセージ 4 行、[X] で履歴。
- Canvas 描画: プレイヤー中心の追従カメラ、16px ドット絵、ランタンの光（周辺を暗く）、見えていない探索済みタイルは雲で覆う。
- 壁は「雲の海」として描く: ふわふわした雲の塊が足場を囲み、ゆっくり上下に揺れる。足場（部屋・通路）は空色の石で、雲の影が落ちる。階段は上り階段。
- 探索済みでも今見えていない範囲は、暗いオーバーレイではなく壁と同じ雲で覆って隠す。近づくと雲がふわっと晴れ、離れると再び覆われる（ミニマップと全体マップには探索済みの形が残る）。
- 未探索の領域は黒ではなく、テーマごとの星雲・星のきらめき・流れ星が視差でゆっくり流れる「夢の宇宙」を背景にする。魔法の光の粒がプレイヤーの周りを漂い、階段は淡く発光し、アイテムは時々きらめく。タイトル画面も同じ星空。
- キーボード: 矢印 / WASD / hjkl+yubn / テンキー、Shift＋方向 = ダッシュ、Space = 攻撃（素振り）、
  [.] [Z] = 待機、[I] 持ち物、[G] / Enter = 足元、[F] 矢を撃つ、[C]＋方向 = 向き変更、[M] マップ、[X] 履歴、[?] ヘルプ。
- スマホ: 8 方向パッド＋ 攻撃・矢・持ち物・足元・ダッシュ・向き・マップ・ログ のボタン。
- 階段に乗ると「のぼりますか？」の確認。ダッシュは敵の発見・アイテム・部屋の出入り・通路の分岐・ダメージで停止。

## セーブ / 記録

- 毎行動後に localStorage へ自動中断セーブ。タイトルの「つづきから」で再開。死亡で消える。
- 記録: 最高到達階・最高スコア・プレイ回数・直近 10 回の履歴。

## 技術

- 純 HTML / CSS / JS（ES modules）。ビルドなし、依存ライブラリなし。フォントのみ Google Fonts（DotGothic16）。
- `js/game/` は DOM 非依存で、Node からスモークテスト（生成検証＋自動プレイ）を実行できる。
- シード付き乱数（mulberry32）。乱数状態もセーブに含まれる。
- GitHub Pages は `main` ブランチのルートから配信。`.nojekyll` あり。
